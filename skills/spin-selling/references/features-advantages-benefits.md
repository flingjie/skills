# Feature / Advantage / Benefit

Three levels of describing a product. Only the third moves a complex sale.

## Feature（是什么）

> 我们的 Agent 支持多模型。

Just a description. No value connection.

## Advantage（有什么好处）

> 支持多模型，所以你可以根据任务切换模型。

Starts to explain a benefit, but still about the product.

## Benefit（为什么对你有价值）

> 如果不同任务可以自动选择最合适的模型，你们是否可以降低成本，同时提高复杂任务的成功率？

Connects the product to the customer's need and the value the customer already
stated.

## The chain

```text
Feature   是什么
  ↓
Advantage 有什么好处
  ↓
Benefit   为什么对你有价值
```

## Rule

In complex sales, Benefit closes deals — not Feature. Before stating a Feature,
know which Problem / Implication / Need-payoff it answers. If you cannot name the
need it serves, it is a feature dump.

## The test

If your product statement could be pasted into any competitor's pitch and still
sound true, you are at Feature level. A Benefit only makes sense for this
customer's specific problem.
