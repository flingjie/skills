# Example: Startup Pitch

A worked example — pitching a startup to an investor or early customer.
Illustrative.

## Situation

向一个投资人/早期客户介绍一个"AI Agent 可观测性"的创业项目。

## Other Person Model

- 角色：投资人（或技术型早期客户）
- 目标：判断这个市场是否成立、团队是否想清楚了
- 痛点：Agent 赛道很热，但大多项目说不清自己解决什么
- 担忧：又是一个"套壳"项目

## Real Problem Hypothesis

- 表面：做一个 Agent 可观测性工具
- 可能根因：Agent 从 demo 到生产最大的阻力是"失败不可复现"，这不是工具问题，是
  缺一套 Evaluation + Learning Loop 的基础设施
- 置信度：medium（需要客户验证）

## Recommended Strategy

用 Pixar Pitch 把"为什么是现在、为什么是这个问题"讲成一个因果链，而不是先讲产品。

## Suggested Conversation（Pixar Pitch）

> 过去，团队主要通过 Prompt Engineering 构建 Agent。随着任务越来越复杂，问题开始
> 出现在 Context、Tool 和 Loop。因此团队不得不花大量时间 Debug。于是我们把 Agent
> 的执行过程变成可观察、可回放、可分析的系统——这就是我们在做的事。

## Next Best Question

> 你们现在有没有一个 Agent 场景，因为"失败后查不出原因"而被卡住？
