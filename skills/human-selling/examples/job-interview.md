# Example: Job Interview

A worked example — self-presentation for an "Agent Architect" role. The "other
person" is the interviewer; the "product" is you. Illustrative.

## Situation

面试一个 Agent Architect 职位。面试官问："介绍一下你自己 / 你现在主要做什么？"

## Other Person Model

- 角色：面试官 / hiring manager
- 目标：判断你能否解决他们的 Agent 规模化问题
- 痛点：招过人但做出来的 Agent 只能 demo，不能上生产
- 担忧：又是一个只会调 API、不懂工程的人

## Real Problem Hypothesis

面试官真正想知道的不是你的技能列表，而是：你能不能把 Agent 从 demo 变成可靠的
工程系统。

## Recommended Strategy

不要 Resume Dump（"我会 Python、FastAPI、LangChain…"）。用
"Identity + Interesting Problem + Open Loop" 结构，让面试官想继续追问。

## Suggested Conversation

> 我主要做 Agent 工程，不过最近一直在想一个问题：怎么让 Agent 不只是 demo，而是
> 真正成为可靠的工程系统——尤其是失败之后能定位、能复现。

## Next Best Question（你反抛给面试官，制造继续对话的 hook）

> 你们现在的 Agent 应用，从 demo 到生产，最难跨过去的是哪一步？
