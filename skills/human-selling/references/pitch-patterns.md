# Pitch Patterns

Do not generate one pitch for every situation — select the format that fits the
context. Prefer clarity over cleverness.

## The formats

| Format | Best for |
|--------|----------|
| One-word | positioning / memorability |
| Question | product intro, consulting, startups |
| Contrast | before/after, demo framing |
| Problem-solution | direct sales, interviews |
| Story | talks, networking |
| Pixar | narrative / investor pitch |

## Question Pitch

> 如果你的 Agent 每次失败都能自动告诉你失败在哪里，你还需要花几个小时 Debug 吗？

## Contrast Pitch

```
Before: 以前，Agent 出错后只能重新跑一次。
After:  现在，可以直接回放执行过程，定位失败节点。
```

## Pixar Pitch

Structure: Once upon a time → Every day → Until one day → Because of that →
Because of that → Until finally.

```
过去，团队主要通过 Prompt Engineering 构建 Agent。

随着任务越来越复杂，问题开始出现在 Context、Tool 和 Loop。

因此，团队不得不花大量时间 Debug。

于是我们开始把 Agent 的执行过程变成可观察、可回放、可分析的系统。
```

## Rules

- Match the format to the audience and the amount of time you have, not to what
  sounds impressive.
- A pitch is the *summary* of the value map, not a replacement for it.
- If you haven't done attunement + problem-finding, you are not ready to pitch —
  go back.
