# Example: AI Agent Sales

A worked SPIN conversation for an Agent solution. Illustrative.

## S — Situation

> 现在这个任务（比如客服工单分类）是怎么完成的？

客户：主要靠人工，几个人每天手动分类。

## P — Problem

> 手工分类这个过程，最耗时、最容易出错的是哪里？

客户：量大、规则多，新人上手慢，还经常分错。

## I — Implication

> 如果任务量继续增加，分错对后续处理会带来什么影响？

客户：错误会被下游放大，客户体验变差，还得返工。

> 随着团队扩大，这种依赖个人经验的分类方式，对培训和稳定性会有什么影响？

客户：会越来越难，新人培训成本很高。

## N — Need-payoff

> 如果 Agent 能自动完成分类，并且每次分错都能回放定位原因，会对效率和成本产生什么价值？

客户：那能省下大量人工，而且出问题能查，稳定性会好很多。
